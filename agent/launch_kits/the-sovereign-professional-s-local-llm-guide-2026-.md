Most advice on private AI starts with model rankings. Start with the workload instead:

1. Sort tasks by sensitivity and difficulty. Keep contracts, client notes, unpublished IP, and personal records local; reserve hosted models for public, high-complexity work only when needed.
2. Size the model to available memory, not benchmark hype. A practical first pass is a quantized 7B–14B instruct model; leave headroom for the context window instead of choosing a model that barely loads.
