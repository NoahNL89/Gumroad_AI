Before you download.

Do I need a dedicated GPU?

No. CPU-only setups can handle smaller quantized models, although generation will be slower. The guide explains sensible starting points by available memory.

Is this software?

No. This is a practical PDF setup and decision guide. It points you through compatible local-model tools and workflows; it is not a hosted application.

Will every model run on every computer?

No. Model choice depends on memory, hardware, quantization, and context length. The guide is designed to prevent unrealistic downloads and poor configurations.

Does “local” automatically mean private or compliant?

No. The guide shows how to verify the whole path—model, runner, interface, tools, folders, and network binding. It does not replace your security, legal, or compliance review.
